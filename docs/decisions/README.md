# Architecture Decision Records

ODW uses Architecture Decision Records (ADRs) for decisions that materially constrain implementation or compatibility.

## Statuses

- **Proposed** — under active evaluation.
- **Accepted** — current project direction.
- **Superseded** — replaced by a later ADR.
- **Rejected** — evaluated and intentionally not adopted.

ADRs should record context, alternatives, consequences, and what evidence would justify revisiting the decision.
